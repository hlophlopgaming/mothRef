MothRef's first downloadable preview: a native reference board for artists.

### Included

- PNG/JPEG reference canvas with pan, zoom, selection, file drops and image paste.
- Version-one `.moth` boards, append-only saves, command journaling, recovery,
  backups and atomic compaction.
- Save/Open path controls, recent files and undo/redo for 256 session commands.
- Bounded GPU texture residency and software-adapter fallback.

### Downloads

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel,
  extract the archive and run `mothref` from Terminal.
- Linux x86_64: extract the archive and run `./mothref`. This binary targets
  Ubuntu 24.04 or a compatible newer distribution; X11/Wayland libraries and a
  working graphics driver are required.

Use the Board path field to enter a `.moth` destination and click Save. Open a
board from an empty canvas, or pass its filename on the command line. SHA-256
checksums are included in `SHA256SUMS`.

### Preview limitations

**This is an experimental prerelease, not the completed M1 reliability release.**
Keep separate copies of important boards and original references.

- The full eight-hour soak and native Windows/macOS manual validation are pending.
- Current limits: 10,000 images per board, 2048-pixel previews and RGBA8 textures;
  runtime compressed-texture support is pending.
- Native Wayland file drops are unavailable; use X11/XWayland, clipboard paste or
  command-line filenames. The 50 ms paste target is not yet met.
- Undo history is not restored after reopening. Opening another board requires
  an empty canvas; multiple-board tabs are planned later.
- Binaries are unsigned and macOS binaries are not notarized. There are no
  installers or automatic updates in this preview.

Local validation passed workspace tests, clippy, license/advisory checks, corpus
round-trips, 1,000 process-kill recovery iterations, and a five-minute seeded
reader fuzz run. See `docs/M1-VALIDATION.md` for the exact scope and remaining gates.

Release CI also passed workspace tests and clippy on Windows, macOS and Linux,
plus license and Android core checks. All published archive checksums and binary
architectures were verified; the GitHub-built Linux executable passed an X11
board-open and SIGTERM recovery smoke test.
