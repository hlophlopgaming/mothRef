This maintenance release fixes packing occasionally leaving rotated images unmoved when floating-point rounding exhausts the layout search. Image sizes and strict fit checks are preserved. A regression test covers the case reported by GitHub CI across all packing heuristics.

All other features and board compatibility remain as in [alpha.11](https://github.com/hlophlopgaming/mothRef/releases/tag/v0.1.0-alpha.11): boards use schema 5 and schemas 1–5 remain readable.

### Validation and limitations

Formatting and Clippy passed for the packing fix. Per maintainer instruction, local tests and benchmarks were not run for this release. Publication requires passing GitHub CI and all four binary builds through the existing release workflow.

This remains an experimental preview. Binaries are unsigned and macOS builds are not notarized. Native platform qualification and the other limitations listed for alpha.11 still apply.
