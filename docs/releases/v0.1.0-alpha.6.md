This preview includes the loading and memory improvements from alpha.5 and fixes Windows release delivery and startup.

### Fixed

- Fix the Windows Clippy unused-import error that blocked release publication.
- Launch the Windows application without opening a console window.

### Included

All alpha.5 improvements are included: configurable image-cache limits, RAM-aware GPU residency, progressive board loading and direct journal-backed originals.
See the [feature and limitation notes](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.6/docs/releases/v0.1.0-alpha.5.md).

### Downloads and validation

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel; extract and run `mothref` from Terminal.
- Linux x86_64: extract and run `./mothref`; Ubuntu 24.04 or a compatible newer distribution and X11/Wayland graphics libraries are required.
- SHA-256 checksums accompany all four archives.
- Formatting, workspace Clippy and workspace tests passed for the fixes. Publication requires passing cross-platform CI.
- Native Windows GUI launch has not been manually checked. Binaries remain unsigned and macOS builds are not notarized. This is an experimental preview; long reliability qualification remains pending. Keep separate copies of important boards and original images.
