This preview adds pen tablet controls and fixes pinning above applications with popups.

### Changes

- Control the board with a pen tablet or pen display. While hovering, the lower pen button pans and the upper button opens the context menu; swap them in Settings › Keys and mouse.
- Ctrl/Command + middle mouse button or lower pen button and vertical drag zooms the board.
- Pen and finger taps no longer nudge images, and touches beginning while a pen is near the screen are ignored for palm rejection.
- Windows receives pen hover, pressure and barrel-button input instead of treating pens as fingers.
- Boards pinned above a chosen application remain above it when it opens a popup, dialog or floating panel on KDE Plasma, X11 and Windows. The active popup stays above the board.
- Fix X11 pinning under window managers that ignore restack requests from inactive applications.

### Validation

- Local formatting and workspace Clippy with warnings denied passed.
- All 352 workspace tests passed locally, with no failures or ignored tests, including graphics golden tests and the new pen-input regressions. The initial sandboxed run could not access local sockets or the application data directory; the unrestricted repeat passed.
- Before the version bump, GitHub CI passed desktop checks on Linux, Windows and macOS, license checks and Android core compilation. Publication requires passing CI for the release commit and all four binary builds.
- Target pinning was checked under KWin 5.27 on native Wayland and XWayland, including popups, switching applications and cleanup when unpinning; see docs/M3-WINDOW-VALIDATION.md.

### Compatibility and limitations

Board compatibility is unchanged: saves use schema 5; schemas 1–5 remain readable.

Real pen/tablet hardware, HiDPI and native Windows/macOS behavior still need qualification. macOS and GNOME target attachment remain open. Binaries are unsigned and macOS builds are not notarized.

Format/import, decoder/cache and rendering code did not change, so corpus, fuzzing, allocation checks and benchmarks were not repeated locally. Tier-3 reliability checks remain CI/maintainer-only. The five-minute soak is reserved for release 1.0.
