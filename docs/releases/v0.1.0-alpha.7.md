This preview adds PureRef-style performance modes with a level-of-detail cache, configurable zoom behavior, tighter mixed-size packing, and simpler image-cache settings.

### Changed

- Add a performance mode to the image-cache settings, as in PureRef: In memory (default), In memory with low zoom quality, Cache on disk and No cache. In the caching modes an image is decoded once per zoom range and later zoom steps reuse the cached detail levels instead of decoding the original again.
- Keep in-memory detail levels within 25% of available RAM (at most 4 GiB) and the disk cache within 2 GiB of the OS cache folder, evicting least recently used entries.
- Fix images that never appeared on Apple silicon and Windows on Arm adapters that report BC texture support: BC7 is now chosen only where it can be encoded.
- Add a persistent smooth/immediate zoom preference and a 1–100% zoom step shared by the toolbar, wheel and trackpad, preserving the pointer anchor and fractional trackpad input across display scales.
- Tap Space to fit the selection, or the whole board when nothing is selected. Space-drag pans without fitting on release; typing does not arm either binding.
- Repack "optimal" so mixed-size images fill free space beside tall images, using their displayed (rotated) bounds and reusing holes instead of leaving whole shelves empty. Zero gap and one-step undo are supported.
- Keep wheel and trackpad scrolling off the canvas while board tools are open.
- Replace the percentage-of-RAM and adapter-automatic image-cache settings with a single persistent 32–512 MiB maximum (96 MiB by default). Automatic eviction under memory pressure is retained.
- Fit-selection now uses rotated bounds, and fitting with an empty selection fits the whole board.
- Keep image residency when closing or reselecting the active board, avoiding a preview reload before the save/discard confirmation.

### Included

All alpha.6 improvements are included: Windows GUI launch without a console window and the Windows release-delivery fix.
See the [alpha.6 notes](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.7/docs/releases/v0.1.0-alpha.6.md).

### Downloads and validation

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel; extract and run `mothref` from Terminal.
- Linux x86_64: extract and run `./mothref`; Ubuntu 24.04 or a compatible newer distribution and X11/Wayland graphics libraries are required.
- SHA-256 checksums accompany all four archives.
- Formatting, workspace Clippy and workspace tests passed for these changes. Publication requires passing cross-platform CI.
- Binaries remain unsigned and macOS builds are not notarized. This is an experimental preview; long reliability qualification remains pending. Keep separate copies of important boards and original images.
