This preview refreshes the window chrome and adds window stacking support for KDE Plasma and GNOME Wayland.

### Changes

- View uses a floating bar revealed at the top edge, with a drag grip, board switcher, pin, overlay and window buttons. Narrow windows put less-used controls in “⋯”; touch users can open Window controls from the context menu.
- Collect reveals window controls over its top bar, uses a restore icon when maximized, and shows board tabs as chips with close buttons inside. Tab reveals window controls for keyboard access.
- KDE Plasma and GNOME Wayland can keep boards, Over and floating views above other windows. GNOME requires the MothRef window extension, installable from Settings › Window and overlay, followed by logging out and in once. Outdated extensions can be updated there.
- KDE Plasma Wayland supports pinning above a chosen window. GNOME restores maximized boards before keeping them above other windows.
- macOS pinned windows appear on every desktop and beside full-screen apps. Windows target pinning handles targets that are themselves always on top.
- Always on bottom is disabled on Wayland, where compositors cannot provide it.

### Validation

- Formatting, workspace Clippy with warnings denied, cargo check and cargo deny passed; cargo deny reports existing duplicate-dependency warnings.
- All 349 workspace tests passed sequentially: 0 failures, 0 ignored, including graphics golden tests and keyboard window-control access. A parallel repeat intermittently failed to acquire a recovery-file lock; the previous parallel run passed that test. CI runs the normal parallel suite and must pass before publication.
- RX 5700 XT: 10,000 distinct images, 100 frames, p99 7.290 ms, 13.32 MiB textures. The previous release recorded 7.658 ms on this GPU. 4K JPEG tile median: 13.854 ms without RAM cache, 0.019 ms with RAM cache (256 KiB).
- The explicit software-adapter benchmark could not run: this environment exposes only the Radeon Vulkan driver and no fallback adapter. Software rendering remains a Linux CI check.
- Corpus, fuzzing and journal stress were not repeated locally because their code did not change in this release.

### Compatibility and limitations

Board compatibility is unchanged: saves use schema 5; schemas 1–5 remain readable.

Native window checks already recorded in docs/M3-WINDOW-VALIDATION.md cover nested KWin 5.27 and GNOME Shell 46 with software rendering. Plasma 6, GNOME 47–49, real hardware sessions, HiDPI, touch/pen and Windows/macOS native behavior still need qualification. GNOME and macOS target attachment remain open. Binaries are unsigned and macOS builds are not notarized.

Tier-3 reliability checks remain CI/maintainer-only. The five-minute soak is reserved for release 1.0. Publication requires passing GitHub CI and all four binary builds.
