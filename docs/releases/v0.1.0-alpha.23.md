This preview adds automatic and custom group colors, clearer nested group titles, selection-aware packing, and faster board opening on supported Linux filesystems.

### Changes

- New groups receive automatic colors. Group menus show preset swatches and a custom RGB picker with numeric channels, Apply and Cancel. Custom colors survive undo, saving, recovery and export.
- Nested group titles avoid overlapping when zoomed out; the inline rename editor follows the same placement.
- Pack and fit respects the current selection, including a single object or members of selected groups. With no selection it packs the board. The camera fits after the layout is journaled.
- Full-resolution mode opens current-format boards faster on Linux filesystems supporting reflinks. It validates a private journal snapshot instead of copying every original. Unsupported filesystems, older or damaged boards, and other performance modes retain the existing copy path.
- Image intake keeps post-import arrangement available for retry when the storage queue is full, preserving its undo group and notification. Adding a single image keeps the current zoom and pan.

### Validation

- Workspace tests: **434 passed**, zero failures, three optional measurements ignored, including headless RGB checks on hardware and software adapters. Six additional disk-backed snapshot/recovery checks passed.
- Formatting, workspace Clippy with warnings denied, and dependency checks passed. All **32** corpus fixtures validated.
- Fifty disk-backed journal process kills lost no acknowledged commands.
- The sandboxed `.moth` fuzzer completed **2,573,750 executions in 91 seconds** without a reader crash, then LeakSanitizer failed because of the sandbox ptrace restriction. The overall fuzz check is **incomplete**; the outside-sandbox retry was interrupted at the maintainer's request. Future checks remain sandbox-only.
- Quick benchmark on llvmpipe: 10,000 images, 100 frames, p99 **32.005 ms**, 13.32 MiB of textures. JPEG tile medians: 13.504 ms without cache and 0.028 ms with memory cache. These software-adapter timings do not establish hardware performance or a regression comparison.

### Compatibility and limitations

Newly saved boards use **schema 8** for custom group colors. Schemas 1–7 remain readable and migrate on save; earlier MothRef releases cannot open newly saved schema-8 boards.

Reflink acceleration requires a supported Linux filesystem and a valid current-format board; other cases use the existing copy path. Native Windows/macOS launch and window-transition checks, and manual interaction with the new group UI, remain unverified in this session. Binaries are unsigned and macOS builds are not notarized. Tier-3 reliability checks remain CI/maintainer-only; long soaks are reserved for 1.0.
