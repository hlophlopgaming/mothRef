This preview makes large imports, moves and saves faster, adds visible save progress, and offers optional backup recovery from the library.

### Changes

- Add up to 100,000 images at once from drag and drop, the clipboard or the file picker. Imports now wait for journal capacity rather than dropping decoded files, and arranging a known file list starts as soon as it finishes. The resize cursor resets after releasing an image or group corner.
- Moving large selections and groups syncs the move once for the batch. On the test board of 1,316 images, the pause after release fell from about 4.6 seconds to 21 ms for loose images, and from 4.4 seconds to 225 ms for a group. Group frames no longer flash back to their old position while the move is being committed.
- Saving writes new live images together with the checkpoint and avoids redundant compaction. First-save median for a synthetic board of 1,000 distinct images (62.5 MiB of originals) fell from 8.70 s to 0.33 s on the test machine. A notice shows the save stage and image count, followed by success or failure. Timed autosaves stay quiet.
- Backup copies are **off by default**, separately from autosave. Enable them in **Settings › General**, or choose **Use global setting / Enabled / Disabled** in a board card's backup menu. Enabled deliberate saves retain the previous three versions. Missing library cards show **Backup available** and **Open backup** when a copy exists. The latest copy opens as an unsaved board for **Save As**, preserving both source files. Existing copies remain available after disabling creation.
- The library remembers up to 100,000 boards and 1,000 app folders, keeps card summaries cached, and reads previews only for visible cards. Folders group boards without moving their files; missing paths can be relinked. Cards support pinning, tags, sorting, showing the file in its folder and moving it to the OS trash after confirmation.
- Exporting originals respects the selection, including selected groups, and uses image names with safe filenames and duplicate suffixes.

### Validation

- Full workspace tests passed: 421 tests, zero failures, three optional measurements ignored. Both the serial and default parallel runs passed.
- Workspace Clippy with warnings denied and formatting passed. All 31 image/board corpus fixtures passed.
- Fifty journal kill checks lost no acknowledged commands; the workspace tests also cover 50 interrupted move batches and 50 interrupted saves with original-image recovery.

### Compatibility and limitations

Boards saved by this release use **schema 7**, including library previews. Schemas 1–6 remain readable; older MothRef versions cannot read newly saved schema-7 boards. Backup preferences are external metadata and do not change board encoding. Backups contain previous saved versions, not undo history or a guarantee of the latest edits; the recovery journal and timed autosave remain separate.

Performance measurements use local fixtures and hardware, not a general timing guarantee; details are in `docs/M2-EDITING-VALIDATION.md`. Native desktop interaction with the new recovery UI, Windows/macOS window behavior and the user's original large board were not manually verified in this session. Binaries are unsigned and macOS builds are not notarized. Tier-3 reliability runs remain CI/maintainer-only; long soaks are reserved for 1.0.
