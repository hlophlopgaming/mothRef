This preview completes the remaining window-mode controls and includes the pending compact-window movement and layout fixes.

### Window controls

- View › Window adds always on bottom, position lock, floating selected images, resize to selected/all items and opacity steps.
- Floating images share the board device, textures and video-memory budget. Up to 32 floating windows can be open. Drag an image to move its window, use edges/corners to resize, and repeat the action with the same selection or press Escape to close.
- Local opacity shortcuts are Ctrl/Command+Alt+Up/Down and can be rebound.
- Settings › Appearance adds custom background, canvas and selection colors, each with a reset to the current theme.
- Settings › Window adds the maximized-window lock policy, click-through recovery on activation, and opt-in system shortcuts: Ctrl+Alt+Shift+T (Over), C (click-through), Up/Down (opacity).
- X11 global shortcuts wait for native events without periodic polling. Windows/macOS use native registrations. Wayland keeps the separate Over controller; unsupported stacking, position and global-shortcut operations remain unavailable.

### Compact-window fixes

- Avoid a Tab/View transition deadlock.
- Keep the window-bar drag area beside its controls.
- Release pointer capture when the compositor starts a native move/resize, so repeated gestures work from the first press.
- Keep Over controls reachable at small window sizes and expose edge/corner resizing in all board modes.

### Downloads

The release workflow builds and attaches the four desktop packages and SHA256SUMS automatically. They may appear after the release page is published.

Board compatibility is unchanged: new saves use schema 5, and schemas 1–5 remain readable.

### Validation and limitations

Local validation passed: all 341 workspace tests (0 failures, 0 ignored), including the floating-image golden with SwiftShader; workspace Clippy, formatting and cargo deny also passed. The quick benchmark on an AMD Radeon RX 5700 XT rendered 10,000 references at p99 6.540 ms (100 frames, 13.32 MiB textures). The five-minute soak was stopped at the maintainer's request and is deferred to release 1.0. GitHub CI is not awaited at the maintainer's request; the existing binary workflow retains its own build/publication checks.

This remains an experimental preview. Windows/macOS native behavior, mixed DPI, compositor-specific transitions and the complete recovery matrix still require manual qualification. Global chords are fixed; Wayland portal shortcuts are not implemented. X11 key grabs use the keymap captured when shortcuts are enabled. Binaries are unsigned and macOS builds are not notarized.
