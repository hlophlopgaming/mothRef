MothRef's second downloadable preview: a native reference board for artists.

### Included

- The reference workspace: a board library with previews, folder filters, search and
  persistent pins and tags; four independent board tabs; an empty-board import prompt
  and a save-on-close dialog.
- Editing tools: a floating tool rail, selection handles, a minimap, image dragging,
  size normalization, and arrange horizontal/vertical/grid/optimal — all reversible.
- Item content transforms: frame rotation, crop, pan, zoom and mirroring, with
  multi-item edits grouped into a single undo step.
- After a drop or paste adds more than five images, a prompt arranges them under the
  cursor as one undo step.
- Importers: BeeRef `.bee` boards (embedded SQLite, layout and stacking preserved),
  static GIF, BMP and bounded WebP previews, plus pasting an HTTP(S) image URL.
- Interface localization: English and Russian, auto-detected on first launch with a
  language picker in the title bar.
- Transparent overlay mode with master opacity, click-through and a separate control
  window.
- Native Wayland file drops and tablet-tool input (pen identity, pressure, hover,
  contact cancellation).
- `.moth` boards (schema 2) with append-only saves, command journaling, recovery,
  backups and atomic compaction.

### Downloads

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel,
  extract the archive and run `mothref` from Terminal.
- Linux x86_64: extract the archive and run `./mothref`. This binary targets
  Ubuntu 24.04 or a compatible newer distribution; X11/Wayland libraries and a
  working graphics driver are required.

Open a board from the library or an empty canvas, or pass its filename on the command
line. SHA-256 checksums are included in `SHA256SUMS`.

### Preview limitations

**This is an experimental early release, not the completed M1 reliability release.**
Keep separate copies of important boards and original references.

- The full eight-hour soak and native Windows/macOS manual validation are pending.
- Notes and transforms BeeRef or PureRef store that MothRef cannot yet represent are
  reported as skipped on import.
- Current limits: 10,000 images per board, 2048-pixel previews and RGBA8 textures;
  runtime compressed-texture support is pending.
- Undo history is not restored after reopening a board.
- Binaries are unsigned and macOS binaries are not notarized. There are no
  installers or automatic updates in this preview.

Local validation passed workspace tests, clippy, license/advisory checks and corpus
round-trips. Release CI runs workspace tests, clippy, corpus checks, the 1,000-kill
recovery run, license and Android core checks, and builds Windows, macOS (Intel/Apple
Silicon) and Linux archives. See `docs/M1-VALIDATION.md` for the exact scope and
remaining gates.
