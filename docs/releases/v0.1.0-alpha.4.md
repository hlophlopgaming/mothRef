This preview replaces the alpha.3 release candidate with a macOS CI adapter fix.

### Fixed

- Headless refinement, adaptive-budget, residency, allocation and app transform
  tests now use the available GPU. They no longer require a software adapter,
  which Metal does not provide on macOS runners. No rendering assertion is skipped.
- Linux CI additionally checks the strict `--software` renderer with Mesa.

### Included

All alpha.3 improvements are included: live selection dragging and sway, smooth
camera/geometry transitions, group fitting on double-click, progressive preview
sharpness, adaptive GPU budgets, PureRef import and expanded editing/export tools.
See the [full feature and limitation notes](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.4/docs/releases/v0.1.0-alpha.3.md).

### Downloads and validation

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: choose `macos-arm64` (Apple Silicon) or `macos-x86_64` (Intel).
  Binaries are unsigned and not notarized.
- Linux x86_64: extract and run `./mothref`; Ubuntu 24.04 or a compatible newer
  distribution and working X11/Wayland graphics libraries are required.
- SHA-256 checksums accompany the four archives. This remains an experimental
  preview; retain separate copies of important boards and original images.
- The original failure was reproduced without a software adapter. Focused clippy
  and all renderer/app tests passed with hardware Vulkan and software llvmpipe.
  Native Metal execution remains for macOS CI; the maintainer requested no wait
  for the full check suite. Long reliability qualification remains pending.
- A separate AMD Mesa OpenGL residency-golden mismatch is recorded in
  `docs/UI-VALIDATION.md`; hardware and software Vulkan checks pass.
