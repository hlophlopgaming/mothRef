This preview fixes the empty-board buttons losing clicks to canvas selection.

### Changes

- Choose files and Paste on an empty board now sit above canvas input. Clicking either button no longer starts a selection, including when creating a board on first launch on Windows.

### Validation

- All 28 moth-ui tests passed, including a regression test clicking both empty-board buttons over the canvas input target and checking that their layer blocks canvas selection.
- Formatting, workspace check and workspace Clippy with warnings denied passed. Publication requires passing CI for the release commit and all four binary builds.
- Native reproduction and verification on Windows remain pending; automated UI checks do not qualify Explorer launch or graphics-driver behavior.

### Compatibility and limitations

The board format is unchanged: schemas 1–6 remain readable. Older MothRef versions that predate schema 6 cannot open schema-6 boards.

Binaries are unsigned; macOS builds are not notarized. Native launch, window transitions, HiDPI, device loss with several windows and real-hardware glass blur remain incompletely qualified; see docs/M3-WINDOW-VALIDATION.md.

Tier-3 reliability checks remain CI/maintainer-only. No rendering or image-decoding changes are included, so no local performance benchmarks were run. The five-minute soak is reserved for release 1.0.
