The first public alpha of MothRef. BeeRef parity, PureRef import and the zoom and memory modes are done; the next milestone is the 0.7 beta (PureRef 2 parity).

### New

- **Color gamut.** Right-click an image › Color gamut shows which hues and saturations the visible part of the image uses, on a color wheel, in three views: gamut windows, painter's cells, and hue shares with the main colors marked. The main colors sort by share, warm to cold, light to dark, hue or saturation; click one to copy its HEX code. **Put on board** adds a gamut card beside the image with a dashed arrow to it. The card keeps its colors if the image is removed, shows **Image changed** when the image is cropped, flipped or reframed later, and **Update color gamut** measures it again.
- **Image sources.** Images remember where they came from: the file, the entry inside a ZIP archive, or the web address. Right-click › **Open source** shows the file in the file manager or opens the address; a file that moved says where it used to be. **Arrange by file path** keeps each folder's images together, numbers by value.
- **Board grid and snapping.** View › Show grid (Ctrl/⌘+') draws dots or lines behind images. Dragged images snap their edges and centers to other images and, with Snap to grid (Ctrl/⌘+Shift+'), to the grid, with guides; hold Ctrl/⌘ to place freely.
- **Menu bar.** Settings › Appearance › Show menu bar adds File, Edit, View, Image, Arrange, Window and Help.
- **Crash reports.** If MothRef closes unexpectedly, the next start explains what happened and offers **Report on GitHub** with the version, system and last log lines filled in, plus Copy report and Open log folder. Settings › For developers › Log has **Report a problem**.

### Fixed

- Windows: attaching above a chosen window keeps MothRef above it after you click that window.
- Running out of video memory no longer closes MothRef; adding many images at once (reported on Windows from about 800) keeps what fits and loads the rest on demand.
- View mode (Tab) shows the whole board again, including groups, their titles, notes and gamut cards. The View popover's Images only option still hides them when wanted.

### Validation

- Formatting and workspace Clippy with warnings denied pass. Unit and CLI tests of the changed crates pass, including the board-grid render golden; CI runs the full suite on Windows, macOS and Linux.
- Format changes (schema 9: image sources and gamut cards): the 35 corpus fixtures validate, including the new `v9.moth`; 50 journal process kills lost no acknowledged commands; the `.moth` reader fuzzer ran 90 seconds twice (about 31–33 million runs each) without a crash.
- Checked by hand on a nested KDE Plasma session: color gamut panel and cards, the Image changed badge and update, menu bar, grid and snapping, and the crash window after a forced kill (and its absence after a normal close).
- Not checked on Windows yet: the attach-above fix and the out-of-memory path. If anything still crashes there, the new crash window carries the log.

### Compatibility and limitations

- Boards are saved as **schema 9**. Older boards open and are upgraded on the next save; **earlier MothRef versions cannot open schema-9 boards**.
- A board shows the paths its images were added from. Gamut cards are not drawn in PNG/SVG/PDF exports yet, and resizing does not snap yet.
- Binaries are unsigned and macOS builds are not notarized.
