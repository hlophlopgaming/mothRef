This preview adds ordinary native CLI commands and stateful JSON automation to the same MothRef binary that runs the GUI. No Python wrapper or extra runtime is required.

### Changes

- Create, inspect, import and edit reference boards using `mothref create`, `add`, `arrange`, `note`, `edit`, groups, transforms, layers and export commands. `--help` documents flags and `--json` supplies machine-readable results and errors.
- Run JSON script files with `mothref batch workflow.json`, or keep a stateful JSON-lines session with `mothref --agent`. Both interfaces use the existing reversible commands, journal and storage worker. Ordinary edits/batches auto-save; raw JSON sessions save on an explicit `save` operation.
- Add local images or explicitly requested HTTP(S) image URLs through the native bounded downloader. Convert `.bee`/`.pur` inputs to a new `.moth` with `mothref open input.bee --output output.moth`.
- Place new images, notes and duplicates beside existing board content by default. Geometry replies include board bounds, rotated object bounds and centers. Explicit positions still support intentional overlap.
- Export original images, folders/ZIPs and native PNG/SVG/PDF scenes. Native preview bundles include pixel-to-board transforms for visual agent workflows.
- Updated GUI and CLI processes share board destination locks. The operation catalog, GUI action coverage and agent guide are embedded in the executable; native CI tests check coverage as functionality grows.
- Includes the published alpha.26 fixes: source-built NASM on Linux/macOS and the updated dependency locks/advisory policy.

### Usage

```sh
mothref create references.moth
mothref add references.moth image-a.jpg image-b.png
mothref arrange references.moth --mode grid --gap 24
mothref info references.moth --json
mothref export references.moth preview.png
```

Run `mothref commands --json` for the embedded operation catalog and agent guide. See the [CLI reference](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.27/docs/CLI.md).

### Compatibility and limitations

- The `.moth` format remains schema 8. Existing GUI file arguments continue to work; subcommands and `--agent` operate headlessly.
- Undo/redo history is bounded to a batch or live JSON session and does not survive process exit. Scripts are sequential; earlier explicit saves/exports are not rolled back when a later operation fails.
- This release does not attach CLI commands to an already running GUI window or automate recovery selection. Do not bypass a busy-board error; older versions or separate recovery roots do not share the new writer locks.
- Scene exports and color sampling use native bounded image previews. Scene export's longest side is capped at 4096; original exports preserve encoded source bytes. Horizontal/vertical flow uses frame sizes; use grid/optimal for rotated references when avoiding overlap.
- Static AVIF limits, build requirements and unsigned/not-notarized binaries remain as documented for alpha.26. Tier-3 reliability gates remain CI/maintainer-only.
