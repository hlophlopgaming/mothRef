This experimental preview replaces the Board tools window with shared action-based controls and a separate, searchable Settings window.

### Changes

- Use a floating bottom toolbar with Select/Hand, Insert, undo/redo, fit and zoom in minus–percentage–plus order.
- Show selection actions above the selection and grouped actions in the context menu, with shared shortcuts and availability. Multi-selection uses one bounding frame with four corner handles.
- Open Settings with Ctrl/Command+comma or the visible Settings button. Search settings from the command palette; changes apply immediately and existing settings-file keys remain compatible.
- Find language under General, input bindings under Keys and mouse, and adapter, memory and journal diagnostics under For developers. Geometry, arrangement, export and pickers have separate editors.
- Add shared light/dark theme tokens, retain the chosen theme and UI scale after GPU recovery, and provide font fallback for menu/change arrows.
- Replace the old status bar with a save-state chip and show all supported image formats on an empty board. The palette has grouped, full-width results with right-aligned shortcuts and a stable layout.
- Board data format, original image bytes and texture-residency policy are unchanged.

### Downloads

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel; extract and open `MothRef.app` in Finder.
- Linux x86_64: extract and run `./mothref`; Ubuntu 24.04 or a compatible newer distribution with X11/Wayland graphics libraries is required.
- `SHA256SUMS` accompanies all four archives.

### Validation and limitations

- Linux validation: workspace check, formatting, Clippy, all 263 workspace tests and `cargo deny check` passed. Socket-based tests ran outside the sandbox with isolated data in `/tmp`; no tests were skipped.
- Quick benchmark passed on llvmpipe (LLVM 22.1.8, 256 bits): 10,000 distinct images, p99 frame time 27.199 ms. This software-adapter result is not a discrete-GPU performance qualification.
- The 300-second soak passed: 2,441 frames, RSS 438,860–452,448 KiB, with a second-half spread of 768 KiB.
- Publication requires passing CI for this commit and all four binary builds.
- The minimap still uses metadata rectangles rather than image thumbnails. The newly documented dark-palette and window-mode designs are plans, not implemented features in this release.
- Double-click focus currently requires Select mode; Hand mode takes the gesture for panning. Use `V` to return to Select.
- Native interaction, physical pen/touch, screenshot comparison, Explorer/Finder launches and graphics-driver transition qualification remain pending. Tier-3 reliability gates remain with CI/the maintainer; no completed milestone or native qualification is claimed.
- See the [UI refactor inventory and qualification notes](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.9/docs/plans/ui-architecture/VALIDATION.md) and [native window matrix](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.9/docs/M3-WINDOW-VALIDATION.md).
- Binaries are unsigned; macOS builds are not notarized. This remains an early preview. Keep separate copies of important boards and original images.
