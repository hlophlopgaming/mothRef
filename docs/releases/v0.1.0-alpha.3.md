MothRef's third downloadable preview improves canvas interaction, image loading
and editing, and adds PureRef board import.

### Included

- Live dragging of the whole selection, Alt-drag duplication, subtle lift and
  grab-point sway. Selection outlines follow the displayed image; released images
  stay in place while storage acknowledges the move.
- Smooth wheel zoom and fit/focus transitions, touch-pan inertia, animated
  appearance/removal and arrangement, hover feedback and appropriate cursors.
  Reduced motion, drag-animation/opacity and outline-visibility preferences.
- Double-click a selected image to fit the entire selected group's width and
  height; double-click the same image again to return.
- Gradual preview sharpening as details load, budgeted coarse fallbacks during
  rapid zoom, and fixes for stale drag ghosts and temporary blank images.
- Adaptive GPU image-cache limits: 1 MiB per image, a 32 MiB nonempty-board floor,
  and ceilings of 512 MiB on discrete GPUs or 96 MiB on shared/software adapters.
  Deleting images lowers the budget and releases excess pages. The status bar
  shows allocated/current-limit memory.
- PureRef `.pur` import for supported embedded images and plain notes, including
  bounded legacy streaming and tested SQLite column-order variants. BeeRef notes,
  rotation and flips are retained where supported. Original source boards remain
  untouched; `.moth` is the working save format.
- Batch alignment, distribution, stacking, layering, normalization and arrangement;
  crop/content transforms, image opacity/grayscale, arrow-key nudges and settings.
- PNG/SVG/PDF scene exports, original-image and ZIP exports, color and coordinate
  tools, English/Russian translation catalogs and native file pickers.
- Runtime BC7 textures on capable adapters with RGBA8 fallback, faster bulk import
  journaling, and clearer saved/journaled/recovery status.
- [Current controls and PureRef shortcut comparison](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.3/docs/SHORTCUTS.md).
  Screenshot bindings are reference material, not an implemented compatibility preset.

### Downloads

- Windows x86_64: extract the ZIP and run `mothref.exe`.
- macOS: use `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel; extract
  and run `mothref` from Terminal.
- Linux x86_64: extract and run `./mothref`. Ubuntu 24.04 or a compatible newer
  distribution, X11/Wayland libraries and a working graphics driver are required.
- `SHA256SUMS` accompanies the four archives. Use `--software` for the fallback adapter.

### Preview limitations and validation

This remains an experimental preview. Keep separate copies of important boards
and original references. The full milestone/release reliability gates are not
claimed complete.

- Unsupported PureRef content is reported; linked images, drawings, rich notes
  and some crop semantics are not fully supported. Import coverage is limited to
  verified samples, not every PureRef version.
- `.moth` saves use schema 4; schemas 1–3 remain readable. Older binaries may not
  read newly saved boards. Undo history is not restored after reopening.
- Preview detail is limited to 2048 pixels per image. Export and color-sampling
  resolution has the limits documented in the changelog.
- Binaries remain unsigned; macOS builds are not notarized. Native Windows/macOS
  manual checks, long reliability runs and idle-machine performance qualification
  remain pending.
- Workspace tests and clippy, software golden images, renderer allocation checks
  and a quick GPU benchmark passed before release preparation. The final quick
  benchmark measured p99 5.982 ms for 10,000 images/100 frames on RX 5700 XT/RADV,
  with 13.32 MiB of image textures. This is not cross-platform qualification.
- No full check suite was repeated for the version bump, per maintainer request.
  The existing release workflow publishes binaries after its builds and CI pass.
