This build replaces alpha.10, whose binary publication was blocked by Windows Clippy and a macOS recovery-path test. It uses the same feature set, fixes the Windows lint, and checks canonical recovery paths through a symlink regression case.

This experimental preview adds Collect/View window modes, shared appearance controls, and improvements to editing, importing and recovery.

### Changes

- Switch Collect / View with Tab and Over with Ctrl/Command+T. Narrow windows use View automatically. View has a sliding window bar, a board switcher and a persistent corner button for touch; mouse, keyboard and context-menu editing remain available.
- Adjust image, board and window opacity, hide notes with Images only, and choose solid, translucent or glass backgrounds from the View popover or Over controller. Glass uses native blur on macOS and explains its translucent fallback elsewhere. Remember presentation locally for 64 saved boards.
- Open BeeRef and PureRef boards as editable, unsaved conversions. Save As .moth or continue without saving; preserve original files, report conversion limitations, and recover imported work after a crash.
- Accept board files independently of single-image size limits, with bounded metadata and payload handling. Import images dragged from local ZIP archives in Gwenview on Wayland.
- Add configurable WASD camera flight or stepped panning, trackpad pan, modifier/pinch zoom, Ctrl/Command-click and rectangle selection toggling, Escape to deselect, and proportional corner resizing.
- Keep dragged images under the pointer while zooming; preserve camera position through editing and undo/redo. Offer arrangement choices and one-step undo after adding images.
- Configure minimap size, placement, opacity and distance from the canvas center in Settings. Keep the minimap proportional to the board and bounded to the viewport.
- Choose image sampling globally or per image, wrap resized notes, retain visible text size during note editing, and open embedded originals in the system image viewer.
- Improve light/dark colors, font readability, translated counts and status messages, menu icons, settings layout, and editor/export feedback. Keep the selection frame at its dropped location while the journal acknowledges a move.
- Preserve original save destinations during journal recovery; archive restored journal bytes and restrict recovery deletion to the app's recovery folder.
- Include the license notices for all three bundled fonts in release archives.

### Compatibility and limitations

- This release writes schema-5 boards for sampling and note layout, reads schemas 1–5, and migrates older files through atomic compaction. Older MothRef releases cannot open newly saved schema-5 boards. Keep separate copies of important boards before upgrading.
- Group-only viewing is pending: the scene has no group membership or group-title selection yet. Presentation history is local, keyed by the board path; moving a board to a new path starts with default presentation.
- Native window-mode transitions, blur, click-through, physical pen/touch and Explorer/Finder launches are not fully qualified across all operating systems. Wayland controls stacking; unsupported controls remain disabled. See the [native window matrix](https://github.com/hlophlopgaming/mothRef/blob/v0.1.0-alpha.11/docs/M3-WINDOW-VALIDATION.md).
- BeeRef/PureRef compatibility covers the verified fixtures, not every feature or file version. The conversion dialog explains retained content and unsupported features.
- The minimap uses metadata rectangles rather than image thumbnails. Grouping and the remaining M3/M4 work are not claimed complete.
- Binaries are unsigned; macOS builds are not notarized. This remains an early preview.

Workspace tests and Clippy were repeated for this correction. Corpus, fuzz, kill-test and performance measurements below are retained from alpha.10 preparation; their implementation paths are unchanged by this Windows codec/test fix. The Windows codec also passed isolated Clippy for `x86_64-pc-windows-msvc` on the Linux host.

- Linux workspace check, formatting and Clippy passed; all 328 workspace tests passed with no ignored tests, including allocation checks and headless rendering goldens. Socket/Wayland tests ran outside the sandbox with test data isolated in `/tmp`.
- `cargo deny check` passed advisories, bans, licenses and sources; existing duplicate-dependency warnings remain.
- All 29 image/board corpus fixtures passed, including `.moth` and PureRef round trips. The 50-kill journal check lost no acknowledged commands.
- Separate 90-second fuzz runs passed: BeeRef 2,090,761 inputs and `.moth` 4,270,596 inputs. LeakSanitizer ran outside the sandbox; no sanitizer checks were disabled.
- Quick benchmark, without a concurrent build or fuzzer: 10,000 distinct images, p99 26.362 ms on llvmpipe (LLVM 22.1.8, 256 bits); textures 13.32 MiB. This is software-adapter evidence, not discrete-GPU qualification. 4K JPEG tile medians: 12.320 ms uncached, 0.028 ms from the bounded memory cache.
- The 300-second soak was stopped at the maintainer's request; no completed soak or memory-plateau qualification is claimed for this release.
- Publication requires passing CI for this commit and all four binary builds. Tier-3 reliability gates remain with CI/the maintainer.
