This preview makes the interface calmer and easier to find your way in: palettes instead of an always-green look, resize handles that show themselves, a resizable navigator, a clearer close prompt and the system dialog for choosing where to save.

### Changes

- Palettes: Settings › Appearance › Palette picks the base colors of the interface, light and dark: Graphite (plain gray, the new default), Ink (cool blue-gray), Umber (warm brown-gray) or Sage (the former green-tinted look). The accent color (formerly “Selection color”), the canvas color and the grayscale tint get one-click color samples next to the color picker. Text on and in the accent now picks its shade by real contrast, so any accent stays readable.
- Saving a board for the first time (Ctrl/⌘+S, or Save when closing) opens the system “Save as” dialog with the board’s name filled in, instead of a field for typing a path. A board converted from .bee or .pur is offered the folder it came from.
- Resize the navigator by dragging the grip in its corner facing the board; the size is remembered.
- Resizing images is easier to find: hovering an image shows its corner handles, the corner under the pointer grows and fills with the accent color and the cursor turns into a resize arrow, and an image can be resized by its corner without selecting it first.
- The dialog when closing an unsaved board is clearer: “Save changes to “board”?”, one line on what is lost, “Don’t save” on its own at the left, Cancel and a neutral Save at the right. Enter saves, Esc cancels.

### Validation

- Formatting and workspace Clippy with warnings denied passed on the release version; all 30 corpus fixtures passed.
- The tests of the changed crates passed after each change (moth-ui 29, mothref 135 at the last run), including new tests for every palette's readability with each accent sample, the resize-handle rule and its drawing, and the autosave timer.
- At the maintainer's request the full workspace test run was skipped for this release. Publication still requires passing CI for the release commit, which runs the workspace tests, and all four binary builds.
- Checked on a nested KDE Plasma 5.27 session: the close prompt in English and Russian, resize handles, navigator resizing, all four palettes and the color samples. The system save dialog could not be shown there (no desktop portal); it uses the same mechanism as the existing Open dialog.

### Compatibility and limitations

The board format is unchanged: schemas 1–6 remain readable. The default palette is now Graphite; boards look the same, but the interface is gray instead of green until another palette is chosen. Custom colors set before are kept.

Binaries are unsigned; macOS builds are not notarized. Native launch, window transitions, HiDPI, device loss with several windows and real-hardware glass blur remain incompletely qualified; see docs/M3-WINDOW-VALIDATION.md.

Tier-3 reliability checks remain CI/maintainer-only. No rendering, decoding or storage-format changes are included, so no local performance benchmarks or kill tests were run. The five-minute soak is reserved for release 1.0.
