This preview reorganizes the board chrome, restores View selection feedback, and adds initial X11 window attachment.

### Menus and shortcuts

- New board, Open, Save, Library and Settings appear directly in the MothRef menu, without a nested File category.
- Navigation and view moves to a compass menu on the bottom toolbar.
- Settings uses Ctrl/Command+O. The previous standard Settings/Open shortcut pair migrates automatically; custom assignments are preserved. Open remains available from the MothRef menu and can be rebound.

### View (Tab) and window pinning

- Window controls and the reveal handle default to the right edge. Settings › Window and overlay can move them to the left; the choice is saved.
- Minimize, maximize/restore and close stay grouped at the selected edge. The Move window button is removed; the handle and free titlebar area remain draggable.
- Multiple selected items retain their selection frame in View while the editing toolbar stays hidden.
- View exposes both pin modes: above all windows and above a selected window.
- X11 attachment selects another application's window and raises MothRef without taking focus whenever that target is activated. A worker waits for native events without idle polling. Escape cancels selection, target destruction releases the pin, and no window is reparented or prevented from moving.
- Fix image/window opacity replacing the canvas background with black or transparent pixels during appearance changes and panning.

### Validation

- All 347 workspace tests passed: 0 failures, 0 ignored. The View selection regression was first reproduced with a failing test, then passed after the fix.
- Formatting, workspace Clippy with warnings denied, and cargo deny passed. cargo deny retains existing duplicate-dependency warnings.
- RX 5700 XT, 10,000 images, 100 frames: repeat p99 7.658 ms with 13.32 MiB textures; previous commit `a22f7e6` measured 7.599 ms under the same setup. The initial current-code run measured 9.152 ms; frame timings vary.
- Explicit software-adapter benchmark passed on llvmpipe: p99 25.240 ms. The workspace tests include opacity, compositing, crop/rotation and resource-budget golden checks.
- An additional attempt with Steam's bundled SwiftShader could not create a device: its compute workgroup Y limit is 128, while the existing device descriptor requests 256. llvmpipe remains the validated software path for this release.

### Downloads and limits

The release workflow builds Linux x86-64, Windows x86-64, macOS Apple Silicon and macOS Intel packages plus SHA256SUMS, and requires passing GitHub CI before publication.

Board compatibility is unchanged: new saves use schema 5; schemas 1–5 remain readable.

Native X11 selection/cancellation, target close, mixed DPI and minimize/restore still need manual qualification. Initial X11 attachment covers normal stacking-layer targets; targets already always-on-top or fullscreen need further handling. Windows/macOS native behavior was not manually checked here. macOS target attachment remains open. Wayland KDE Plasma/GNOME attachment is deferred. Tier-3 reliability checks remain CI/maintainer-only; the five-minute soak is reserved for release 1.0. Binaries are unsigned and macOS builds are not notarized.
