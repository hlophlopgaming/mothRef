# UI icons

Exported from the MothRef Penpot mockup (file "mothref", page "MothRef · desktop UI"), one SVG per `icon / <name>` group.

- Outline style: `stroke-width="1.75"`, round caps and joins, no fills.
- Colour is `currentColor`, so the UI theme decides it (the mockup uses the text, muted and accent colours on the same glyphs).
- Each file keeps the size it has in the mockup:
  - 12 px: `check`
  - 14 px: `x`, `folder`, `chevron`
  - 16 px: `plus`, `search`, `grid`, `clock`, `star`, `trash`, `tag`, `settings`, `menu`
  - 18 px: toolbar and tool-rail icons
  - 20 px: `eye`
  - 48 px: `image` (drop zone)
- File names are kebab-case versions of the layer names (`zoomIn` → `zoom-in.svg`).
